# 중미 스페셜티 프로필 검토

검토일: 2026-09-08 (Asia/Seoul). 기존 중미 29개 산지와 새 Turrialba·Orosi·Tres Ríos 3개를 검토했다. 후속 검토에서 기존 가이드 중 Matagalpa의 상충 자료만 정정했으며 UI는 수정하지 않았다.

산출물은 `specialty-research/central.ts`의 32개 프로필·63개 고유 로트와 `specialty-research/new-central-guides.ts`의 검증 정보가 포함된 신규 가이드 3개다. 고유 출처 URL은 79개다. 분류는 focus 27, standard 5; 모든 focus는 최소 2개 로트가 있다. 이 수는 생산량·농장 수·품질 등급이 아닌 자료의 구성 수다.

## 분류와 로트 구성

focus는 공식 대회 기록, 반복 전문 취급 또는 여러 전문 업체가 취급하는 추적 가능한 생산자·품종·가공 사례를 근거로 판단했다. 모든 지역을 유명도만으로 focus에 넣지 않았다. Cobán, West Valley, Pluma Hidalgo, Orosi, Tres Ríos는 구체 로트는 있으나 현재 확보한 자료의 폭·반복성·농장 구분이 상대적으로 제한되어 standard로 두었다. 확인된 자료가 있는 이 32개에서는 background를 강제로 배정하지 않았다.

동일 농장의 서로 다른 품종·가공 로트는 별도 예시로 제시하되 농장 수를 늘려 세지 않는다. 상위·하위 산지에는 같은 로트 URL을 복사하지 않았다. Bonita Springs는 Alto Lino로, Jaramillo·Alto Quiel·Bambito는 실제 세부 위치에 배정했다. Nueva Segovia의 두 농장은 Mozonte여서 Dipilto의 두 농장과 겹치지 않는다. 향미는 각 로트 원문에서만 가져왔고 농장 품종 목록을 모두 상품의 구성 품종으로 옮기지 않았다.

## 코스타리카 거래 산지와 기관 권역

ICAFE의 기존 개별 산지 페이지는 Orosi·Tres Ríos를 별도로 설명하며 지금도 검색 본문에서 확인된다. 반면 [2025-06-22 El Financiero의 ICAFE 홍보 책임자 인터뷰](https://www.elfinancierocr.com/economia-y-politica/tres-rios-desaparece-del-mapa-de-las-regiones/YPE3AYVL7JHVFOHPLYZM3VWHQM/story/)는 Orosi→Turrialba, Tres Ríos→Valle Central의 조직·홍보권역 통합을 설명하고 기존 두 명칭의 사용은 계속 가능하다고 명시한다. 인터뷰 기사 본문을 직접 읽었다. 이 보도를 현행 법률 원문 검증으로 주장하지 않는다.

이에 신규 세 항목은 현재의 ‘공식 8대 산지’라고 부르지 않고 전통 커피 거래 지리로 작성했다. 기관 권역 변경을 근거로 거래 산지의 이름이나 실제 농장 위치를 자동 정규화하지 않았다. Orosi는 Guanacaste의 Orosí 화산과 구별한다. 신규 가이드는 같은 이름의 지형과 거래권역 혼동을 피하고 농장 자료의 노트임을 verification에 기록했다.

## 직접 열람과 검색 본문의 범위

직접 열기에 실패했지만 검색 도구가 반환한 해당 페이지의 전체 상품/산지 본문을 읽어 채택한 자료는 WatchHouse Bonita Springs, Green Coffee Collective Bambito Yellow Catuai, WASA Azul, Ally La Isla Catigua Semi Washed, Ally Aquiares Centroamericano Anaerobic Honey, ICAFE Orosi/Tres Ríos, Opal Santa Teresa PDF다. 이 경우를 직접 사이트 열람 성공으로 기록하지 않는다. Opal의 상품 행 자체는 직접 읽었다. 모든 실패 후보를 검증했다고 간주한 것이 아니며, 필요한 농장·산지·가공·품종·향미가 실제 반환 본문에 함께 있는 경우만 사용했다. 아래 위임 대조표의 Sucafina Finca El Salvador와 Montecoyote Moonstar도 동일한 제한이 있다.

그 외 채택한 파나마·과테말라·코스타리카 로트 페이지와 생산자 보완 자료는 직접 본문을 읽었다. 배경 설명이나 판매 페이지가 갱신·품절될 수 있으므로 출처 접근일은 열람한 2026-09-08로 고정했다. 경매 연도·상품 출시명·PDF 경로·입항일·로스팅일은 수확연도로 전환하지 않았다.

## 날짜·표현 원칙 및 검증

수확연도 필드는 상품에 실제 harvest/crop 날짜가 명시된 5개 로트만 채웠다: Don Jaime 2022/23, La Bastilla 2023/24, La Finca 2024/25, Chelín 2025/26, Pompilio의 2026년 1–3월. COE 대회 연도, 출시명, 입항일, 로스팅 날짜는 수확연도와 구분했다.

각 향미는 해당 로트의 공식/생산자/수입업자/로스터 본문에서만 뽑고 원문 설명을 긴 문장으로 복제하지 않았다. 일반적인 산지 향미나 품종의 전형적 향미를 빈 로트에 보충하지 않았다. 여러 품종을 심는 농장에서도 상품 표의 실제 로트 품종만 사용했다. 일반 판매 로트와 대회 출품 로트의 관계는 따로 유지했다.

공식 COE 문서·판매 로트가 아닌 검색 요약 집계 서비스는 최종 근거에서 제외했다. 검색 본문만 접근된 두 최종 출처(Sucafina Ruffatti, Montecoyote Moonstar)는 표에 별도로 표시했다. 전체 웹을 빠짐없이 조사했다는 의미는 아니며, 지정된 14개 산지를 빠짐없이 검토했다는 범위다.

이 추가 산출물은 출처마다 짧은 사실 필드와 향미 항목만 담았다. 통합본에서 동일 URL의 기존 가이드·품종 근거까지 함께 쓰는 경우에는 원문별 200단어 한도를 누적 적용해야 한다. 특히 Royal CJ1636와 Cafe Imports 오퍼 표는 기존 자료와 같은 출처일 수 있다.

최종 검사는 regionId 14개 일치·중복 없음, 전체 28개 로트의 필수 필드·한영 노트 수·출처·날짜 형식, focus 로트 최소 2개, 상위/하위 ID 간 동일 로트 URL 중복 없음을 확인한다.


## 통합 확인

32개 ID가 중복 없이 기존 담당 29개와 새 3개에 대응한다. 각 프로필의 내부 분류 근거·출처, 63개 로트의 생산자·위치·품종·한영 가공·한영 노트·출처를 검사했다. 모든 focus의 로트 수는 2개 이상이고 각 로트에는 1개 이상의 검증 출처가 있다. 새 가이드의 flavorSourceUrls는 모두 해당 sources 안에 존재한다. 현재 재고·지역 보장 점수·품종 계보·생산량 순위는 추가하지 않았다.
