## 출처 충돌과 처리

- 가투쿠자 대회 상세 경로는 검색 결과는 있었지만 본문 재접근이 실패했다. 향미 근거로 유지하지 않았다. [2019년 공식 결과표](https://allianceforcoffeeexcellence.org/burundi-2019/)에서 수상이력만 확인했다. 워시드 판매자료와 대회 내추럴은 별도 로트로 명시했다.
- 가투쿠자 대안으로 읽은 [Covoya 페이지](https://www.covoyacoffee.com/burundi-ets-nduwayezu-natural.html)는 URL·일부 본문과 제목·가공 항목이 충돌했다. 최종 출처에 넣지 않고 일관된 List + Beisler 자료를 사용했다.
- Theri 페이지의 세부 표와 제목은 Murang’a를 가리키지만 본문 일부는 Embu로 적는다. 충돌하는 문구를 채택하지 않았으며 Murarandia·Gatagua 자료를 함께 대조했다.
- Daye Bensa의 Shantawene와 수카피나의 Bensa Shantaweni 자료를 이름만으로 동일 시설이라고 확정하지 않았다. 각 자료의 역할을 분리하고 상이한 고도를 합치지 않았다.
- Café Imports의 오래된 광역 행정 묶음을 현재 행정구역으로 복사하지 않았다. Sidamo는 검색용 표기이며 Guji·Yirgacheffe를 현재 Sidama 아래로 이동하지 않았다.
- 부룬디의 Kayanza·Ngozi는 출처에서 쓰이는 커피 유통 산지명으로 유지했다. 최신 행정구역 경계를 이 데이터로 확정하지 않는다.

## 확인 범위와 남은 한계

최종 파일에는 64개 출처 연결, 중복을 제외한 53개 URL이 있다. 각 향미 URL은 같은 항목의 `sources`에도 존재한다. 확인일은 재검색·본문 검토일이며 수확연도, 2026년 재고 또는 현재 판매 보증을 뜻하지 않는다. 향미가 출처에 적혀 있다는 사실을 검증했으며 직접 커핑을 수행한 것은 아니다.

산지 전체로 일반화할 수 없는 고도는 숫자 범위 필드에 채우지 않았다. 본문에 남은 숫자도 시설과 공급 농가 범위를 구분한다. 품종·가공 목록은 확인한 생산 사례를 모은 것이며 해당 지역의 전수 재배 통계가 아니다. 판매량·스페셜티 생산량 순위는 확인된 통계가 없어 추가하지 않았다.
