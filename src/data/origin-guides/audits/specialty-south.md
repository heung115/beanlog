## 추가 산지

- Quindío: Gardelli는 해당 Pink Bourbon이 Calarcá El Placer에서 생산됐다고 명시하고 실제 수확을 2021-11로 제공한다. El Placer가 다른 지역의 체리를 처리하는 별도 상품까지 Quindío 재배로 간주하지 않았다. mosto 첨가를 가공에 보존했으며 원문에 있는 Pink Bourbon 유전계보 주장은 사용하지 않았다.
- Quindío: El Fénix Wush Wush는 Scenery의 Anoxic Natural 쪽 cup 노트만 사용했다. 같은 페이지 PLOT Mosto Washed 노트는 섞지 않았다. 명시된 실제 수확 2024-05~08과 2024/25 crop 표기를 구분했다. Tabi는 Green Coffee Collective의 별도 anoxic washed 상품이다.
- Valle del Cauca: 생산자 직영 CGLE 원문에서 Las Margaritas=Caicedonia, Cerro Azul=Trujillo를 확인했다. Sudan Rumé Hybrid Washed와 Geisha Napoleón Natural의 각 노트만 사용했다. XLIII #00281의 2025 Hybrid Washed는 별개 로트로 유지했다. 범용 농장명 El Paraíso만으로 Valle del Cauca에 배정하지 않았다.
- Espírito Santo: 주 전체이며 Montanhas do Espírito Santo를 별칭으로 넣지 않았다. Incaper 개관과 Cecafes 자료, Castelo Bela Vista 및 Afonso Cláudio Alto Lagoa의 개별 거래 자료를 조합했다. Conilon 존재를 설명하지만 두 Arabica 로트의 향미를 Conilon 전체로 확장하지 않았다.
- 새 가이드의 altitude 범위는 생략했다. 개별 농장 고도를 주 전체 범위로 만들지 않았다.

## 제한·접근 실패·제외

- DANDY Karol Ortega Sidra는 검색 색인 본문을 읽었지만 직접 열람이 실패해 최종 로트에서 제외했다. 대체로 직접 본문이 읽힌 Wadi·Silverbird·Swerl 사례를 사용했다.
- Nueva Alianza 2021 농장 디렉터리 재열람 실패 후, 심층 로트는 직접 읽은 Project Origin과 Moonwake 상품으로 바꾸었다. 공식 COE 결과표는 역사적 참여 근거로만 남겼다.
- La Loma Laurina의 제목·본문은 Natural, 표는 Washed로 불일치하여 이번 로트에서 제외했다.
- Ally La Roca Natural은 이전 라운드 직접 열람 실패가 반복되어 직접 열리는 September Pink Bourbon 상품을 사용했다.
- Seam El Fénix는 직접 열람에 오류가 있어 신규 가이드의 근거로 사용하지 않았다. Raw Material·Scenery·Green Coffee Collective에서 읽은 본문으로 대체했다.
- COE, 판매·입고·관계 시작 날짜, 웹 파일명은 harvest와 구분했다. 품절 페이지도 역사적 로트 근거로 유지하되 현재 재고·구매 가능성을 주장하지 않는다.
- flavorNotes는 정확한 선별품의 시음값이며 지역 평균이나 해당 품종의 유전적 향미가 아니다. 관련 상품 추천 영역, 다른 가공, 고객 리뷰의 타 커피 노트를 혼합하지 않았다.
- 한국어·영어 향미는 대응되는 짧은 노트로 저장했다. 평점·가격·품종계보·품질 보장 문구를 추가하지 않았다.
