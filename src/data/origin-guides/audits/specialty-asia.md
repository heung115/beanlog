# 아시아·태평양 스페셜티 로트 감사

검토일: 2026-09-08. 대상은 기존 가이드 22개 전부다. 결과는 `../specialty-research/asia.ts`에 저장했다. 22개 프로필, 고유 상품·출품 로트 27개, 상·하위 산지의 로트 참조 42개, 고유 출처 URL 31개다. 우선순위는 focus 16개, standard 6개, background 0개다.

## 판단 범위

- 생산자·수입사·해당 상품을 직접 판매하고 평가한 로스터의 자료와 Coffee Board 공식 출품 기록을 사용했다. 제삼자 상품 디렉터리는 후보 발견에만 사용했다.
- `focus`는 전문 거래의 반복성, 구체적인 대표 생산자 또는 공식 대회 근거를 반영한다. `standard`인 Flores, Bajawa, Kerala, Wayanad, Buôn Ma Thuột, Mattari는 확보한 로트의 구체성을 인정하되 전문 거래 폭이나 복수 생산자 증거가 상대적으로 좁다.
- Wayanad·Kerala에서도 Thomas가 생산한 Luna의 원산지·가공·향미가 확인돼 background로 분류하지 않았다. 이를 지역 전체의 파인 로부스타 등급이나 공식 대회 입상으로 확대하지 않는다.
- 번호가 있는 개별 로트와 생산자의 가공별 상시 상품을 구분해 이름을 보존했다. Sulotco, Luna 등 수확연도나 계약번호가 없는 상품에는 임의 로트 번호를 만들지 않았다.
- 상위 산지에서 같은 로트를 재사용하는 것은 탐색 관계다. 해당 마을·농장의 컵 노트를 섬·주 전체의 공통 향미로 바꾸지 않았다.

## 로트의 감각 정보 대조

향미는 각 상품의 tasting note, cup profile 또는 해당 번호의 분석 본문에서만 뽑았다. 한 출처의 여러 제품 중 다른 상품의 노트, 고객 리뷰, `You may also like` 영역의 노트는 사용하지 않았다.

- Ratu Ketiara는 Chris Kornman의 해당 컵 분석, Ribang·Lintong 숙성은 Sweet Maria’s의 해당 상품 커핑 본문을 사용했다. 숙성 로트의 담배·목재 느낌을 린통 전체의 필수 향미로 바꾸지 않았다.
- Frinsa Sarapan과 Edun, Sulotco 워시드와 내추럴, Laga Lizu와 Nola Wonga의 노트를 분리했다. Toraja G1 Washed의 감귤·녹차를 Sulotco Washed 상품에 섞지 않았다.
- Konkua는 계약 P118342/1, Baroida는 ZHYVAGO의 Morita 워시드 상품, Mong은 각각 Enjoy와 Dandy가 평가한 상품을 사용했다.
- Kerehaklu는 71시간 꽃 배양 발효 상품, Ratnagiri는 Covoya의 56시간 진공 발효 상품과 Naivo의 더블 워시드 상품을 구분했다. 다른 농장이나 같은 농장의 유사한 상품명만으로 품종을 채우지 않았다.
- Sandalkad는 공식 책자의 2019년 출품분에 한정한다. 현재 수입사의 별도 발효 상품 노트를 붙이지 않았다. Luna는 제품의 명시적인 세 가지 노트를 사용하고 FAQ의 로부스타 일반 묘사는 제외했다.
- Hoà Thuận은 Every Half의 2024년 Cà Sẻ·Mosto-natural 항목에 대응한다. 같은 기사 앞부분의 Liberica에 붙은 사과·풍선껌 노트, 다른 현행 TR4 허니 상품의 노트를 가져오지 않았다.
- CJ1645는 해당 분석의 퍼지 브라우니·콜라·무화과·석류, CJ1677은 해당 overview의 꽃·과일·차 노트를 사용했다. Mattari Lot 205의 45일은 건조 기간이고 무산소 발효는 140시간이다.

## 수확연도와 미공개 정보

수확연도는 8개 고유 로트에만 기록했다. Lintong 2023/24, 숙성 Lintong 2021, Frinsa Edun 2024, Baroida 2025–2026, Ratnagiri 2024/25, Hoà Thuận 2024, Haraz CJ1645 2024/25, Haraz CJ1677의 원문 `October–February 2026`이다. CJ1677의 시작 연도는 문서가 별도로 쓰지 않아 2025라고 보정하지 않았다.

Ratu Ketiara, Naivo Ratnagiri Double Washed, Luna는 로트 품종을 비웠다. 앞의 두 상품에는 신뢰할 수 있는 해당 상품의 구체 품종이 없었고, Luna는 아라비카 품종 Kent와 로부스타 종 표기가 서로 맞지 않는다. 이는 해당 지역에서 품종이 재배되지 않는다는 판단이 아니다.

## 접근과 검사 기록

웹 검색과 원문 열기로 대조했다. Dandy의 개별 상품 직접 열기는 오류가 났지만 검색 도구가 반환한 해당 개별 URL의 전체 상품 본문에서 생산자·지역·품종·가공·감각 문구를 읽었다. 컬렉션 페이지 직접 열기에는 다른 시점의 상품 목록이 나와 감각 근거로 쓰지 않았다. 검색 결과를 전부 원문 직접 열기 성공으로 기록하지 않는다.

구조 검사 결과: 기존 아시아 가이드 ID와 22개 프로필의 완전 일치, 중복 ID 없음, 프로필당 1–3개 로트, focus 16개 모두 2–3개 로트, 모든 로트의 이름·생산자·위치·양언어 가공·양언어 향미·출처 존재, 한·영 노트 수 일치, 로트 출처의 상위 프로필 포함, 31개 출처의 HTTPS·메타데이터·검토일 확인을 통과했다. 담당 파일 ESLint와 독립 TypeScript 검사도 통과했다. 신규 데이터와 본 감사 파일 외의 파일은 수정하지 않았다.

## 추가 지역 독립 표본 검토

별도 작성된 `additional.ts` 중 중국 2개·태국 2개·동티모르 2개·Kintamani 1개, 총 7개 프로필의 9개 로트를 독립적으로 대조했다. 아래 8개 커피 자료는 원문 직접 열기에 성공했으며 생산자·위치·품종·가공·향미의 중대한 불일치를 발견하지 않았다. 이는 위 22개 프로필의 27개 고유 로트 집계에 포함되지 않는다.
