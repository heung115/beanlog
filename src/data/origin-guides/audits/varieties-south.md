# 남미 품종별 생산자 근거 조사

검토일: 2026-09-08. 대상은 기존 남미 산지 22개 전부다. 기존 가이드와 향미는 수정하지 않고 `variety-research/south.ts`에 품종·산지·생산자 연결 56건을 별도 기록했다. 콜롬비아 35건, 브라질 15건, 페루 6건이며, 고유 품종 표기 28개와 출처 URL 30개다.

직접 연결은 21개 산지다. Cajamarca에서 확인한 두 세부 산지는 Jaén·San Ignacio ID로 기록하므로 상위 집계가 필요하다. 나머지 부모 산지도 자식 항목을 중복 기록하지 않는다. 같은 지역·품종의 여러 사례를 무작정 늘리지 않고 확인한 농장 또는 생산자 프로그램을 보존했다.

## 기록 기준

- 생산자, 직접 거래 수입·수출업자, 해당 커피를 구매한 로스터의 상품·농장 설명, 출품자가 제출한 경매 주최기관 기록을 읽었다. 기록된 것은 공개 자료가 지지하는 재배 또는 로트 원산지다.
- 지역 수준의 일반 품종 목록만으로 농장을 추정하지 않았다. 농장 재배 목록과 특정 판매 로트의 품종을 구별했다. 둘 모두 품종 존재의 근거가 되지만 같은 혼합 로트라는 뜻은 아니다.
- 유전적 계보, 품종 간 동일성, 카페인 수치, 재배량·우점 비율, 등급·시음 점수는 추가하지 않았다. 가공명·브랜드·프로젝트명이 품종으로 들어가지 않게 했다.
- 2009·2018·2021년 경매 또는 상품 기록은 연도를 명시했다. 농장 품종 목록은 과거 상품 페이지에 실려 있어도 그 품종의 특정 수확 로트가 있었다고 확장하지 않았다.
- 철자 통일: Geisha/Panama Gesha→Gesha, Sidra Bourbon→Sidra, SL-28→SL28, Ají→Aji, Maragogype→Maragogipe, Acauã→Acaua, Guará→Guara, Topázio→Topazio. 이는 이름 정리이며 유전적 동등성 검증이 아니다. Yellow Maragogipe와 Red Striped Bourbon 등의 수식어는 유지했다.

## 핵심 근거 위치

실제 데이터에는 각 레코드의 모든 출처 객체를 저장했다. 아래는 묶음별 읽은 구간을 재검토하기 위한 링크다.

- [Ally La Loma](https://www.allycoffee.com/coffees/la-loma-laurina-natual/): Farm info의 Pitalito와 재배 목록. 표의 Washed와 제목·본문 Natural이 불일치하여 이 자료에서 가공 정보를 추가하지 않았다.
- [Touton El Diviso](https://www.touton-specialty-coffee.com/en/p11552): Growing region과 farm narrative. Ají·Sidra의 계보 표현은 가져오지 않았다.
- [Sucafina Villa Betulia](https://sucafina.com/na/offerings/luis-anibal-papayo-fw): Details와 About This Coffee의 현재 재배 목록. [MASTEFI](https://mastefi.com/)는 Quebraditas 상품의 지명과 품종만 사용했다.
- [Banexport Juan Martín](https://www.banexport.com/farm-juan-martin): Location과 Current varieties. [Ally El Zacatin](https://www.allycoffee.com/coffees/el-zacatin-chiroso-natural/): Farm info의 재배 목록.

## 제외·접근 제한

- Ally의 La Roca 페이지는 검색 본문이 보였지만 직접 열기가 실패했다. 해당 URL을 증거 배열에 넣지 않고 직접 거래한 Fresh Farmer 및 September의 읽을 수 있는 본문으로 교체했다.
- 정부 RAP Boston 2022 PDF는 웹 도구의 파일 크기 한도를 초과했다. Tolima 2025 지역 PDF는 텍스트 추출 결과가 비어 있었다. 둘 다 최종 근거로 쓰지 않았다.
- Wilson Mamani의 Scenery 블로그와 Efrain의 Vignette 상품은 직접 열기에 실패하여 증거에 포함하지 않았다. 전자는 공식 COE의 다른 Cusco 농장 기록, 후자는 직접 읽은 Falcon 생산자 자료로 대체했다.
- Peru Java 검색에서 나온 JAVA Coffee는 로스터 브랜드였으므로 품종으로 추가하지 않았다. SL9/Inca Gesha 및 Marshell의 동일성·재분류 설명은 이번 단순 품종 목록에 확정해 넣지 않았다.
- Inzá로 판매된 과거 상품을 가진 Andrés Martínez가 현재 소유한 두 농장은 검색 자료에 Cauca까지만 확인됐다. 과거 상품 이름으로 두 농장 모두 Inzá라고 추정하지 않았다.
- Brazil Sítio São Pedro는 COE 표와 농장 상세의 지역 범위가 달랐다. 상세에 Canastra가 명시되어 Sul de Minas로 강제 배정하지 않았다. Orfeu Laranjal의 지역 분류도 엇갈려 보류했다.
- Belco의 Pantano 표기는 한 페이지에서 terroir 필드이고 설명 농장은 Rio Brilhante였다. 동명의 Pântano 농장으로 합치지 않았다. Mauro Galheri의 Pântano 자료는 Wagner Ferrero 자료와 별도로 취급했다.
- Veloso 구사이트는 본문 접근 실패, De Luca Vian 목록은 구체적 농장·생산자 연결 부족으로 제외했다. 범위가 다른 산지의 좋은 후보를 숫자를 채우기 위해 옮겨 넣지 않았다.

## 완료 검사

ESLint와 담당 파일의 엄격 TypeScript 검사를 통과했다. 실행 검증에서 56건 모두 유효한 기존 지역 ID·품종·생산자·출처를 가지고 있고, 지역–품종 중복이 없음을 확인했다. 직접 연결 21개에 자식 산지의 상위 집계를 적용하면 22개 전부가 연결된다. 출처 확인일은 전부 2026-09-08이다. 브라질 최종 교차 검토에서 Topazio의 연도 오해 가능성을 발견하여 생산자 이름 뒤의 2021 표기를 제거했다.
