# 아시아·태평양 산지 재검증

검토일: 2026-09-08. 대상은 `asia-pacific.ts`의 22개 산지 전부이며, 지역 12개와 세부 산지 10개를 유지했다. 웹에 공개된 기관·생산자·수입사·로스터 자료를 대조한 날짜이지 새 수확분을 직접 커핑한 날짜가 아니다.

22개 모두 향미 근거 범위, 구체적인 상품·생산자 또는 지역 설명, 향미를 실제로 지지하는 URL을 `verification`에 기록했다. 지역 설명 3개, 지역 설명과 생산자 사례 병행 1개, 상품·로트·생산자 사례 18개다. 생산자 여러 로트의 공통 소개도 `lot`으로 보수적으로 분류했다. 향미는 재배지 자체의 보장된 속성으로 해석하지 않는다.

## 열람 경로와 남은 제한

- 직접 페이지 열기가 실패해도 검색 도구가 같은 URL의 본문을 반환한 경우, 그 반환된 문장과 상품 정보만 대조했다. 해당 항목은 Sandalkad 워시드 상품, Vietnam Coffee Republic Bourbon 상품, Trenggiling 유통명 설명이다. 페이지 전체의 최신 상태를 확인했다고 주장하지 않는다.
- 베트남 지식재산청의 기존 GI PDF는 직접 열기에 실패했다. 검색 도구가 반환한 해당 PDF의 Buôn Ma Thuột 절과 동 기관의 2022년 GI 변경 안내를 읽고 수종·공정·넓은 생산권만 확인했다. 현재 행정경계 전체를 다시 확정한 것은 아니므로 화면에서도 ‘등록자료’로 범위를 한정했다.
- Covoya 기존 URL과 대체 CA URL은 직접 열기에 실패했다. 추가 검색으로 실제 열리는 P613877-1 상품을 찾아 교체했다. 향미 근거는 이 상품에 억지로 옮기지 않고 IAC의 명시된 행에 유지했다.
- 부온마투옷 로스팅 상품은 농가 실명·생두 가공·수확 연도를 공개하지 않는다. 공통 향미, 파인 로부스타 점수나 전체 생산 품질을 보증하는 근거로 사용하지 않는다.
- 인도·베트남 일부 판매자 본문에는 과장된 품질 주장, 가공과 향미의 단순 인과 설명, 서로 다른 고도 수치가 있다. 필요한 상품 라벨·자사 노트만 사용했고 점수·생산량·원인 설명은 옮기지 않았다.
- 부모 관계는 탐색용 커피 산지 관계다. 기존 3단계 Bababudangiri → Chikmagalur → Karnataka를 유지했다. 같은 지명이 아닌 마을·큰 행정구역을 별칭으로 넣지 않았다.
- 향미 URL이 각 산지의 `sources` 안에 있는지, 검토 날짜와 한·영 설명이 모두 있는지, 부모 ID와 한·영 노트 개수가 맞는지 22개 전부 자동 검사했다. 고도 수치는 새로 추정하지 않았다.
