# 아프리카 스페셜티 후속 보강 감사

검토일: 2026-09-09. 담당 범위: 아프리카 27개 산지. 변경 데이터: `specialty-research/africa.ts`만 수정. 공개 summary/environment, 품종 연구, 다른 대륙 파일은 수정하지 않았다.

## 결과와 집계 기준

- 27개 프로필, 실제 사례 52 → 65개. 신규 사례 20개를 채택하고 기존 7개를 교체·제거했다. 같은 로트의 판매처만 바꿔 사례 수를 늘리지 않았다.
- 모든 산지에 2–3개 사례. 단일 사례였던 Harrar와 Gatukuza 모두 2개가 됐다. 편집 우선순위는 기존대로 유지했다.
- 명시 수확연도에 2025가 포함된 산지는 6 → 24개. 그중 22개는 2025년 또는 2025/26 수확, 2개(Gatukuza·Othaya)는 2024/25까지 확인된다. 이 24개를 모두 2025/26 작황으로 간주하지 않는다.
- Harrar·Kilimanjaro·Mbeya 3개는 생산자, 품종, 가공, 향미와 명시 작황연도가 함께 확인되는 최근 사례를 아직 확보하지 못했다. 자료 부족을 지역의 품질 부족으로 해석하지 않는다.
- 기존 최근 작황 6곳은 이번에 1차 본문을 다시 열어 수확 필드와 해당 로트 내용을 대조했다. 새 정보의 날짜는 실제 열람일 2026-09-09로 기록했다.

## 단일 사례 2곳의 독립성

### Harrar

Keffa의 Mamush Kabtimer / Micheta Gr 1 내추럴은 기존 Paper Plane의 Abdirashid Abdullahi / Queen City 사례와 생산자가 다르다. Keffa 페이지의 생산자·지역·가공·품종·향미를 같은 본문에서 확인했다. 표기 오류 Barries와 Carmel은 각각 berries와 caramel로 정리했다. New crop에는 연도가 없어 harvest는 비워 두었다.

### Gatukuza

Small Planes의 [Gatukuza Lot 20](https://static1.squarespace.com/static/57a4cd746a496311f31cf815/t/5e96fd98b990fc5b6c5a5246/1586953624898/Gatukuza%2BLot%2B20.pdf)는 Gashikanwa / Ngozi, Bourbon, washed, 3개 대표 향미가 동일 PDF에 명시된다. Harvest Season 필드에는 April–June만 있지만 본문이 해당 구매 시즌을 2019 수확 부진과 같은 해 Gatukuza 선정으로 설명하여 2019를 기록했다. PDF의 파일 경로나 업로드일에서 연도를 추정한 것은 아니다. Long Miles는 소싱 파트너이며 Gatukuza를 소유한다고 표시하지 않았다.

Granell의 [Gatukuza 상품](https://cafesgranell.es/es/especialidad/857-burundi-gatukuza-cafe-especialidad-250-g.html)은 Bourbon / washed / Cosecha 2024/2025와 향미가 같은 상품 본문에 있다. 앞선 2019 사례와 다른 작황이다. 검색 도구가 반환한 생산자 사이트의 전체 상품 본문 및 별도 검색 엔진의 해당 필드를 대조했다. **실시간 직접 열람은 HTTP 403이었고 추출 도구도 본문을 받지 못했다. 따라서 직접 접속 성공으로 기록하지 않는다.** 로스팅일 05/26은 수확연도가 아니므로 채택하지 않았다. 2025/26 작황은 아직 미확인이다.

## 자료 해석의 경계

모든 신규 향미는 해당 판매자·수입원의 특정 로트 본문에서만 가져왔다. 다른 작황, 가공, 농장의 노트를 합치지 않았다. 연도 없는 기존 사례는 유효한 실제 사례로 유지할 수 있지만 최신 수확으로 표시하지 않는다. 중배전 등 명시된 로스팅 조건은 로트 이름에 남겼다. 새 사례의 수확연도는 상품명·SKU·입고일·커핑일·URL 연도와 구분했다.

향미가 충분한 자료와 최근 작황의 증거가 각각 존재해도 동일 로트라는 연결이 없으면 결합하지 않았다. 이 때문에 Tanzanian 2025/26 공급 자체가 없다는 결론이 아니라, 현재 요구한 필드를 모두 갖춘 사례 확인이 미해결이라는 결론이다.
