## 정보 기준

- 국가별 대표 향미를 모든 지역에 복제하지 않습니다. 지역 소개와 실제 생산자·워싱스테이션·수입 로트의 향미를 구분합니다.
- 개별 농장이나 로트의 고도를 지역 전체 범위로 확대하지 않습니다. 지역 범위가 확인되지 않으면 altitude를 생략합니다.
- 스페셜티 설명은 추적 가능한 생산 사례, 가공·품종의 다양성, 공식 원산지 자료 등을 소개합니다. 생산량 순위나 모든 원두의 점수·등급을 보장하는 표시가 아닙니다. 개념 참고: [SCA의 스페셜티 커피 정의](https://sca.coffee/what-is-specialty-coffee).
- 지역별 sources는 자료 발행자, 제목, URL, 대조한 날짜를 담습니다. 날짜는 수확연도나 해당 페이지의 갱신일을 뜻하지 않습니다. 일부 발행자 페이지는 직접 열기 제한이 있어 검색에 노출된 발행자 본문으로 대조했습니다. 아프리카의 상세 접근 기록은 로컬 docs/origin-research-africa.md에 있습니다.
- aliases에는 같은 장소의 다른 철자·언어 표기와 확인된 기존 입력 표기만 넣습니다. 더 넓거나 좁은 지명, 협동조합·농장명은 별칭으로 합치지 않습니다.
- parentId는 커피 유통 지리를 따라 탐색하기 위한 관계입니다. 예가체프–게데브 같은 관계를 현재 행정구역의 포함 관계로 단정하지 않습니다.

## 수정 위치

- africa.ts: 에티오피아·케냐·르완다·부룬디·탄자니아
- americas-south.ts: 콜롬비아·브라질·페루
- americas-central.ts: 파나마·과테말라·코스타리카·온두라스·엘살바도르·니카라과·멕시코
- asia-pacific.ts: 인도네시아·파푸아뉴기니·인도·베트남·예멘
- additional-countries.ts: 볼리비아·에콰도르·우간다·중국·태국·동티모르와 국가 목록
- additional-regions.ts: 기존 국가에 추가한 산지 10곳
- types.ts: 공통 필드 정의. index.ts: 검색, URL, 상하위 탐색, 원두 기록 추천 연결

id는 공개 페이지 주소의 기준이므로 설명을 수정할 때 유지합니다. 새 세부 지역은 같은 국가의 유효한 parentId를 연결하고, 한국어·영어 텍스트 및 실제 출처를 함께 작성합니다. 로트만으로 확인한 특징은 본문에 해당 로트의 예시라고 명시합니다.

기존 origin-presets.ts는 원두 라벨 파서·좌표 등에서 쓰는 호환 목록으로 유지합니다. 새 가이드는 별도의 편집 원본이며, 기존 원두나 원시 지명 데이터베이스를 다시 쓰지 않습니다. 웹 관리자의 기존 원시 산지 카탈로그 편집과도 별도입니다.

## 연결되는 화면

- 첫 화면: 국가만 표시. 검색은 접힌 상태로 시작하며 펼쳐서 국가·산지명·별칭·향미·품종으로 검색
- 기본 탐색: 국가 → 상위 산지 → 연결된 하위 지역. 검색 결과에서는 일치하는 지역에 바로 접근
- 국가 페이지: 최상위 산지 가이드로 연결
- 산지 페이지: 환경, 향미와 로트 예시, 품종·가공, 스페셜티 배경, 하위 지역, 출처
- 원두 기록: 선택 국가·산지에 맞는 세부 지명 추천. 기존 사용자 입력을 보존하고 API 장애 때에도 검증된 추천 제공
- 원두 상세: 저장된 상하위 관계와 일치하는 가장 구체적인 가이드로 연결. 모순되거나 알 수 없는 지명을 임의 재해석하지 않음
- 사이트맵: 한국어·영어의 모든 산지 주소 포함

## 검증

기존 60개 산지 누락, 중복 ID·URL, 잘못된 부모·순환 관계, 국가 경계를 넘는 추천, 별칭 충돌, 출처 형식, 원두 기록 연결, 중첩 주소의 404 처리를 검사합니다. 브라우저 검증에는 한국어·영어의 전체 산지 페이지와 검색·필터·모바일·키보드·자바스크립트 없는 검색을 포함합니다.

## 노트 근거 재검토 (2026-09-08)

각 항목의 `verification`에는 실제 자료를 대조한 날짜, 향미 근거의 범위(`regional`: 지역을 설명한 자료, `lot`: 특정 상품·생산자 로트, `mixed`: 두 종류를 함께 사용), 한영 설명, 향미를 지지하는 출처 URL을 기록합니다. 이는 직접 시음 결과나 품질 인증이 아닙니다. 지역 자료도 작성자의 매입 범위나 특정 연도 관찰일 수 있으므로 `flavorContext`에 그 한계를 적습니다.

- 출처 제목만 일치하는 것으로 검증을 끝내지 않고 생산지·품종·가공·노트 본문을 대조합니다.
- 농장 최대 고도, 가공소 고도, 여러 지역 합산 범위는 지역 재배 고도로 옮기지 않습니다.
- 특정 상품이 삭제되거나 가공 방식이 모순되면 대체 자료를 찾고 설명을 함께 수정합니다.
- 검색 결과로만 확인한 자료와 직접 읽은 본문은 지역별 `audits/*.md`에서 구분합니다.
- `tests/origin-verification.test.mjs`는 모든 산지에 근거 설명이 있고, 향미 URL이 해당 산지의 출처 목록에 연결되는지 검사합니다. 자동 검사는 사실 검증을 대신하지 않습니다.

재검토 결과: 26개국 121곳. 향미 근거는 지역 설명 19곳, 개별 로트 94곳, 혼합 8곳이며, 인용 URL은 219개입니다. 항목별 대조 결과는 [검토 기록](audits/README.md)에 보관합니다.
