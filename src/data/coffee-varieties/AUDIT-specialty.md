# 스페셜티 품종·명칭 검토

확인일: 2026-09-09. `specialty.ts`에 16개 항목을 기록했다. 모든 항목은 확인 가능한 사실만 포함하며, 확정할 수 없는 부모 계통과 일반 향미는 비워 둔다. 아래 내용은 내부 감사 기록으로 화면에 노출하지 않는다.

## 최근 유전 연구와 범위

- **Sidra:** [Tapia-Armijos et al., Frontiers in Plant Science, 2026-07-14](https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2026.1868034/full). 실제 원문 날짜는 7월 14일이다. 검색 엔진의 상대 날짜는 채택하지 않았다. VINKA 한 농장의 네 형태형에서 대표 개체를 유전 검사했으며, 두 Sidra 형태형은 Core Ethiopia에 속했다. Sidra 이름으로 구입한 또 다른 개체는 Batian과 양립하는 표지형이었다. 이 제한된 표본을 모든 Sidra 유통분의 동일 유전자형 또는 혼입률로 확대하지 않는다. 사이트 분류는 population이며, Bourbon × Typica 확정 계보는 제외했다.
- **Pink Bourbon:** [Café Imports, 2023-09-26 검사 보고](https://www.cafeimports.com/north-america/blog/2023/09/26/pink-bourbon-cryptozoology-and-genetics-in-specialty-coffee/). 직접 검사를 의뢰한 주체의 결과 기록이다. 2017년 두 형태의 나무, 2023년 다섯 표본을 비교했다. 2023년은 Pink Bourbon 네 표본과 Orange Bourbon 한 표본이며 모두를 순수 Pink Bourbon으로 기록하지 않는다. 일부는 혼합 시료다. Pink Bourbon을 Red × Yellow Bourbon 교배로 표시하지 않았고, 전체 유통명과 하나의 유전형을 동치로 만들지 않았다.
- **Chiroso:** [Montagnon et al., 2021](https://link.springer.com/article/10.1007/s10722-021-01139-y)의 조사 표본은 Ethiopian landrace와 연결된다. 현지 재배는 [Pana Café](https://www.panacafe.com.co/)의 우라오 생산 정보와 교차 확인했다. 관습명 Caturra Chiroso를 별칭으로 보존하지만 Caturra 돌연변이라는 확정 계보는 부여하지 않는다.

## 생산자 명칭과 동명이종

- **Bernardina:** [Café Pacas의 생산자 기록](https://cafepacas.com/website/?p=172)에 근거해 Los Bellotos 발견과 관리자 이름의 유래, 발견 농장의 고도를 채택했다. 공개된 원시 유전 자료가 없는 ‘세계에 알려지지 않은 품종’ 주장이나 Gesha 유사도 수치는 채택하지 않았다. 과육에서 묘사한 과일 맛을 볶은 원두의 일반 향미로 옮기지 않았다.
- **Wush Wush:** [Proud Mary의 직접 거래 농장 기록](https://www.proudmaryacademy.com/en/articles/6986547-producer-oscar-and-nancy-maca-popayan-cauca-colombia)에서 El Zafiro 재배목의 형태와 2017년 세 가공 공동 출시만 채택했다. 에티오피아에서 콜롬비아로 들어온 연도와 경로는 추정이라 생략했다. 에티오피아의 동일 명칭 연구기관 선발종과 El Zafiro 재배목을 유전적으로 동일하다고 단정하지 않는다.
- **Ombligon:** [Genuine Origin의 El Diviso 직접 상품 기록](https://www.genuineorigin.com/colombia-finca-el-diviso-natural-2024)에서 재배자·지역·명칭의 형태적 유래만 사용했다. Pacamara/Bourbon 변이 또는 Ethiopian landrace라는 여러 추정은 제외했다. WCR의 베네수엘라 [Monte Claro](https://varieties.worldcoffeeresearch.org/varieties/monte-claro)에도 Ombligon 별칭이 있지만 콜롬비아 El Diviso 재배목과 같다는 증거가 없으므로 병합하지 않았다. WCR 영문/스페인어 별칭의 Papayo 차이도 자동 매핑하지 않았다.

## 선발 계통

- **Pacas:** [WCR](https://varieties.worldcoffeeresearch.org/varieties/pacas)의 1949년 발견, Bourbon 왜성 변이, 1960년 ISIC 선발을 사용했다.
- **Villa Sarchi:** [WCR](https://varieties.worldcoffeeresearch.org/varieties/villa-sarchi)의 Bourbon 변이, 알라후엘라 발견, 강풍 내성을 사용했다. Villalobos라는 단독 명칭은 다른 품종을 가리킬 수 있어 별칭에서 제외했다.
- **Maracaturra:** [WCR Pacamara의 별도 Maracaturra 기록](https://varieties.worldcoffeeresearch.org/varieties/pacamara)을 사용했다. 자연 교배는 probable 수준을 유지했다. Café Imports 용어집의 브라질 19세기 기원과 WCR의 니카라과 기록이 달라, 공개 설명은 중미 선발 이력과 미고정 특성에 집중했다. Pacamara와 같은 이름으로 매핑하지 않는다.
- **Gesha 1931 / Gori Gesha / Illubabor Forest:** [Gesha Village 생산자 설명](https://www.geshavillage.com/the-village/)에 근거했다. 1931은 현대 수집 연도로 기재하지 않는다. Gori Gesha의 실제 종자 수집 연도는 2011년이며, Illubabor Forest의 수집·선발 배경은 1974년이다. Gesha 1931의 Panama 유사 선발을 T2722 유전적 동일성으로 바꾸지 않았다. Illubabor Forest를 특정 JARC 번호와 연결하지 않았다.
- **74110 / 74112:** [Royal Coffee CJ1246, p. 2](https://cdn.royalcoffee.com/wp-content/uploads/2018/10/21123013/CJ1246_Ethiopia-Banko-Chelchele-Tariku-Mengesha-Raised-Bed-Natural-Crown-Jewel.pdf)의 Getu Bekele·Tim Hill 품종 연구 요약을 사용했다. [에티오피아 현장 시험 논문](https://scialert.net/fulltext/?doi=je.2019.74.81)에서도 두 번호를 CBD 저항성 시험 재료로 별도 취급한다. Royal 보고서는 생육 형태와 연도의 출처이며, 시험 논문은 농업 재료 및 CBD 특성만 뒷받침한다. 두 계통을 Kurume 또는 서로의 별칭으로 합치지 않았다.
- **Kurume / Wolisho:** [Café Imports 용어집](https://www.cafeimports.com/north-america/blog/coffee-variety-glossary/)의 지역 재래형 설명과 Royal의 생산자 품종 표기를 사용했다. JARC 번호와 형태가 비슷하다는 이유로 같은 품종으로 통합하지 않는다. 한국어 음역과 철자 변형만 별칭 처리했다.

## 자료 한계와 검증

생산자 직접 기록과 수입자의 실제 거래·검사 기록은 각자의 관찰 범위로 제한했다. 검증된 과학적 계보와 같은 증거 수준이라고 간주하지 않는다. Sidra·Pink Bourbon 등의 최신 연구 결과도 특정 검사 표본과 재배 집단에 관한 결과다. 미래 보강은 독립 표본과 종자 계통 추적 자료가 확보될 때 진행한다.

Node TypeScript 로딩으로 core와 합친 39개 ID의 고유성 및 정규화된 별칭 충돌 부재를 확인했다. 동일 URL에서 유래하는 한영 공개 설명을 core까지 합산해 모두 200단어 미만임을 확인했다. 화면과 산지 연결 검사는 상위 작업에서 별도로 수행한다.
