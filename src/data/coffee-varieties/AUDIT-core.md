# 핵심 품종 검토

확인일: 2026-09-09. 대상: `core.ts`의 23개 항목. 재배 품종 22개와 범위가 넓은 Gesha 유통명 1개를 구분한다. 모든 항목은 한영 설명과 개별 1차 출처를 가진다. 이 기록은 내부 검토용이며 화면 문구가 아니다.

## 범위와 판단

- WCR 개별 품종 카탈로그의 계통, 생육, 육종 기록을 중심으로 작성했다. 대량 원문 전재 없이 짧게 재서술했다. 한영 합산으로 같은 URL에서 유래하는 공개 설명은 200단어 미만이다.
- 일반 Gesha/Geisha는 `trade-name`, 파나마 T2722 후손은 별도 `selection`이다. 일반명에 파나마의 향미나 농업 특성을 부여하지 않는다. Gesha 1931, Gori Gesha, Green Tip Geisha를 T2722 별칭으로 등록하지 않았다.
- 분류 값은 사이트의 표시 체계다. WCR의 유전군 명칭과 동일한 분류 체계라고 주장하지 않는다. 복합 품종과 미고정 품종도 재배 품종으로 기록하되 본문에 실제 구조를 남긴다.
- Bourbon의 색상 변이, Caturra·Catuai의 색상별/번호별 선발을 상위 품종의 동일 별칭으로 합치지 않는다. 일반 Bourbon과 Red Bourbon도 자동 동치 처리하지 않았다.
- WCR Obata 출처는 Red 한정이다. 일반 Obata 또는 Yellow Obata를 Red Obata 별칭에 넣지 않았다.
- Typica 페이지의 지역 관습명 Blue Mountain, Sumatra 등을 자동 별칭으로 쓰지 않는다. 산지명/별도 선발과 혼동될 수 있다.
- Java는 Abysinia 개체군 유래의 품종이다. 자바 섬에서 재배된 모든 커피를 이 품종으로 보지 않는다. AB3·BPL10 등 별도 품종을 자동 통합하지 않았다.
- SL28은 Bourbon 관련, SL34·SL14는 Typica 관련 유전 배경으로 분리했다. SL34의 역사적 French Mission 설명을 근거로 Bourbon 계통이라고 단정하지 않았다.
- Pacamara는 ISIC의 Pacas × Maragogipe 교배에서 유래한다. 안정화된 순계나 F1 품종이라고 단정하지 않는다. 직접 열기는 캐시 오류였으나 WCR 공식 영문 검색 색인에서 계통과 형질을 확인했다. 스페인어 페이지에는 컵 품질에 관한 상충 문장이 있어 이를 채택하지 않았다.
- Ruiru 11은 Catimor 모계와 복합 교배 부계의 F1 복합 품종이다. Batian은 일부 Ruiru 11 부계 F5에서 선발한 세 순계의 복합 품종이다. 둘을 단일한 순계나 서로의 별칭으로 표기하지 않았다.
- Parainema의 선충 저항성은 일부 Meloidogyne에 한정된다. 모든 선충에 강하다고 확대하지 않는다.
- IHCAFE 90와 Lempira는 온두라스에서 녹병 감수성이 확인됐다. Catimor 혈통만으로 현재 녹병 저항 품종이라고 표시하지 않았다. T5175·T8667 페이지의 Lempira 경유 계보에는 일관되지 않은 부분이 있어, 두 품종의 개별 페이지가 공통으로 명시하는 부모 교배까지만 채택했다.
- Marsellesa의 과거 육종 목적과 현재 저항성 평가는 다르다. 현재 개별 페이지의 intermediate를 반영했다. Batian과 Ruiru 11의 녹병 문구는 내성(tolerance)으로 보수적으로 표현했다.
- 고도는 위도에 따라 달라지므로 하나의 범용 미터 범위로 환산하지 않았다. 국제 품종 시험의 수량 수치를 모든 지역의 기대 수량으로 옮기지 않았다.
- 꽃·자스민·복숭아는 WCR가 명시한 파나마 Geisha에만 사용했다. 다른 품종에 전형적 과일 향미를 만들어 붙이지 않았다. Marsellesa의 산미 역시 개별 품종 자료에 근거한다.
- Laurina는 CIRAD 저자 연구 기록으로 Bourbon 자연 변이, 낮은 카페인, 짧은 마디와 수형을 확인했다. 저카페인을 무카페인/디카페인으로 표현하거나 특정 고정 함량을 부여하지 않았다.

## 로컬 검증

- Node의 TypeScript strip 실행으로 배열 로딩, 23개 ID의 고유성, 필수 한영 필드와 HTTPS 출처를 검사한다.
- 동일 URL을 공유하는 일반 Gesha/파나마 Geisha의 설명은 합산해 단어 예산을 점검한다.
- 실제 산지에 연결하는 별칭 해석과 화면 통합은 상위 작업의 검사 대상이다. 이 파일만으로 전체 페이지가 검증됐다고 간주하지 않는다.
