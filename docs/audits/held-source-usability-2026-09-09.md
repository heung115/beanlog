# 보류 출처 사용 가능성 재판단 — 2026-09-09

## 판단

114개 출처 호스트를 현재 사용 방식에 맞춰 다시 판단했다. **조건부 사실 사용 가능 73곳, 보류 유지 29곳, 판단 근거 부족 12곳**이다. 권리자의 허가를 받은 결과나 무위험 보증이 아니라, 확인한 조항에 근거한 실무상 사용 판단이다.

조건부 사용은 산지명·품종·가공·고도와 짧은 일반 향미 용어를 독립적으로 서술하는 경우다. 원문의 창작적인 설명문과 그 번역, 사진, 상품 목록의 편집·배열, 데이터베이스의 상당 부분을 재현하는 경우는 포함하지 않는다. 향미는 해당 랏의 관능 기록이며 지역 전체의 고정 특성으로 확대하지 않는다.

자동 수집 금지 자체를 모든 사실의 게시 금지로 확대하지 않았다. 그러나 현재 자료가 과거에 자동으로 수집됐을 수 있으므로, 사실을 다시 서술하는 것으로 당시 취득의 문제까지 해결되었다고 보지 않는다. 조건부 사용 판단은 추가 크롤링 허락도 아니다.

## 대표 사례

- **Onyx·Sample Coffee:** 짧은 생산 사실의 독립적인 게시를 조건부 사용 대상으로 판단. 자동 수집과 보호 콘텐츠 복제 제한은 그대로 구분한다.
- **Melbourne Coffee Merchants:** 짧은 사실 사용은 조건부 후보이나, 24개 출처 및 웹 목록 PDF의 누적 추출·목록 재현 범위는 별도로 고려해야 한다. 바로 전체 자료를 복원할 수 있다는 의미가 아니다.
- **Sucafina:** 다른 웹사이트·전자 검색 시스템 저장까지 명시한 조건과 누적 편입을 고려해 현재 추출자료는 보류 유지. [공식 약관](https://sucafina.com/na/terms-of-use)
- **Covoya·Algrano·Tasting Grounds:** 데이터·정보의 외부 게시 또는 체계적 수집·DB 편입을 직접 다루는 제한을 고려해 보류 유지.
- **DRWakefield·일부 논문 출처:** 문언 충돌이나 개별 자료의 조건 미확인 때문에 사용 가능 판정을 내리지 못한 항목은 근거 부족으로 유지.

## 실제 보류 랏과의 관계

출처 114곳과 화면에서 제외된 고유 랏 122건은 다른 단위다. 기존 랏 보류 원장은 출처 조건에 따른 67건, 근거 부족·충돌·미승인 수정 등의 55건으로 나뉜다. 이번 출처 판단만으로 122건 전체가 복원 가능한 것은 아니다. 조건부 사용 출처라도 생산지·품종·향미의 사실 검증이 확인된 필드만 사용해야 한다.

현재 데이터에 참조된다는 표시는 원천 데이터·출처 연결이 있다는 뜻이며, 해당 랏이 지금 화면에 노출된다는 뜻은 아니다. 운영 공개 목록이나 출처 보류 정책을 자동 변경한 것은 아니다.
